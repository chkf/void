# Tasks

各组共同构成首个完整版本。验收需记录实际运行的设备、系统、签名和结果。

## 1. 原生工程与宿主

- [ ] 1.1 建立可构建的 Swift/SwiftUI iOS 工程和共享 scheme，划分设计中的十二个模块与原生渲染器。用 Xcode 构建并冷启动宿主。
- [ ] 1.2 实现原生项目列表、运行页、独立管理 sheet、设置及恢复入口。用 UI 测试走通首次选择项目、重开直达上次项目及从失效页面返回管理的路径。
- [x] 1.3 写入 `docs/ARCHITECTURE.md`、`docs/RUNTIME.md`、`docs/BUILD.md` 和可重复的构建脚本。按文档从干净检出构建，核对部署目标、依赖锁定和签名配置。
- [x] 1.4 用 SwiftUI 源码编写默认项目视图，在 iOS 模拟器检验绑定、开关、重开和源码不匹配提示，用 Xcode 27.2 构建并发布可下载的 IPA。

## 7. 十八组系统能力

每组接入真实框架、类型、统一错误和适用权限，随实现维护 SDK 参考中的使用示例。功能明细与成功场景见 [原生 SDK 规格](specs/native-sdk/spec.md)。

- [ ] 7.1 接入文件操作、选择、共享、进度与文件监听。验证追加、移动、元数据、导出及超出项目根的读取被拒。
- [ ] 7.2 接入 Photos 和 Camera。用真机及真实媒体验证有限访问、多选与保存、原生预览、摄像头切换、支持的各项控制及退出后的资源释放。
- [ ] 7.3 接入 Audio 和 Video。录制再播放真实片段，验证会话、路由变化、暂停恢复、转码、截图、进度和导入导出。
- [ ] 7.4 接入 Location。验证授权、精度、位置、航向、正逆地理编码、订阅和取消，并分别记录可用硬件和后台条件。
- [ ] 7.5 接入 Calendar、Reminders 和 Contacts。验证系统记录的查询与增删改、提醒完成状态、日历写入与读取权限差异以及联系人可见范围。
- [ ] 7.6 接入 Notifications。用真实本地通知验证定时、重复、取消、分类、待处理状态以及点击后的项目归属。
- [ ] 7.7 接入 Bluetooth 和 NFC。用真实 GATT 外设及 NFC 标签验证服务发现、读写、订阅、断开、NDEF、会话取消和不可用结果。
- [ ] 7.8 接入 HealthKit 和 HomeKit。用有相应签名和授权的设备验证健康类型查询及允许的写入、家庭配件和场景。核对隐私限制及无相应条件时的错误路径。
- [ ] 7.9 接入 Security 和 System。验证 Keychain 跨项目隔离、加密往返、哈希、生物识别，以及系统分享、链接、方向、亮度、设备状态、文档预览等已注册操作。
- [ ] 7.10 接入 Network。用测试服务验证各 HTTP 方法、WebSocket、上传下载、进度、超时、取消和证书错误，核对策略覆盖重定向目标。
- [ ] 7.11 接入 Graphics & Compute 的原生图像和媒体处理、SQLite 与大文件分块。验证绘图、Wasm、计算结果与数据库持久化可在同一项目组合使用。
- [ ] 7.12 生成 `docs/SDK_REFERENCE.md`。逐项对照十八组能力的 Swift 注册、TypeScript 定义、示例、权限与可用性，运行契约测试并检查遗漏。
