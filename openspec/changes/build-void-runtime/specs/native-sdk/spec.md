# Spec Delta

## Purpose

Agent 可以通过同一套 TypeScript 接口编写使用设备能力的应用。下面十八组能力对应原计划第六章，每组规定实际可观察的结果，便于在具备硬件、系统授权与签名的设备上验收。

## ADDED Requirements

### Requirement: Filesystem

SDK SHALL 提供 readFile、writeFile、appendFile、deleteFile、copyFile、moveFile、mkdir、readdir、stat、exists、watch，以及选择、导入、导出、分享和读取文件元数据。访问按授权项目根、项目数据、缓存及宿主私有边界检查。

#### Scenario: 读写并分享项目文件

- **WHEN** 项目创建目录、写入后追加文件内容，并请求分享该文件
- **THEN** 项目读回完整内容、收到变更通知，并在系统分享面板中看到所选文件。对宿主私有路径的读取返回拒绝。

### Requirement: Photos

SDK SHALL 支持系统选择器单选或多选照片和视频、读取所选资源与媒体信息、生成缩略图、保存图片和视频、查询适用权限，并遵循有限照片访问范围。

#### Scenario: 仅选择部分照片

- **WHEN** 用户通过系统选择器只选一张照片和一个视频
- **THEN** 项目可读取两项选择结果及其缩略图，选择本身不触发完整照片库授权。

### Requirement: Camera

SDK SHALL 提供相机权限检查、原生预览与页面混合显示、拍照、录像、结果保存，以及设备支持的前后切换、闪光、对焦和曝光控制。

#### Scenario: 在页面中预览并拍摄

- **WHEN** 用户在有摄像头且已授权的设备打开项目预览并拍照
- **THEN** 原生预览与页面控件同步显示，拍摄返回可读取的媒体文件，离开页面释放摄像头。设备缺少的控制项返回具体原因。

### Requirement: Audio

SDK SHALL 提供麦克风权限、录制与播放、暂停与恢复、会话管理、音频格式、播放音量、音频导入导出及路由变化事件。

#### Scenario: 录音后切换播放路由

- **WHEN** 用户授权录音，录制片段后播放，并在播放过程中断开耳机
- **THEN** 录音文件可导出和重新播放，项目收到真实路由变化，可据此暂停或恢复播放。

### Requirement: Video

SDK SHALL 提供本地视频播放控制和进度、信息读取、缩略图、指定时间截图、导入导出及支持格式的转码。

#### Scenario: 转码和截图

- **WHEN** 项目导入支持的视频，将它转码到可用格式，并请求指定时间帧
- **THEN** 返回可重新打开播放的输出文件及对应图像，无法解码或编码的格式返回媒体错误。

### Requirement: Location

SDK SHALL 提供当前位置、持续位置和航向事件、精度设置、正逆地理编码及权限查询，按设备与系统实际允许的精度和运行模式返回结果。

#### Scenario: 有限精度下订阅定位

- **WHEN** 用户仅允许大致位置并开始订阅，随后取消订阅
- **THEN** 项目获得系统提供的精度和位置，取消后停止接收该订阅的位置事件。

### Requirement: Calendar

SDK SHALL 提供日历列表、按日期范围查询事件和事件的创建、修改、删除，区分系统提供的写入权限及可读取日历的权限级别。

#### Scenario: 只有写入授权

- **WHEN** 系统仅授予写入访问，项目创建事件后请求读取日历
- **THEN** 创建产生真实日历事件，读取请求返回需要相应访问级别的结果。

### Requirement: Reminders

SDK SHALL 提供提醒列表管理及提醒事项的查询、创建、修改、删除、到期时间和完成状态操作。

#### Scenario: 完成提醒

- **WHEN** 已授权项目在指定列表创建带截止时间的提醒，再将其标记完成
- **THEN** 系统提醒事项中可看到相同的时间和完成状态，再次查询得到相同记录。

### Requirement: Contacts

SDK SHALL 提供权限查询、联系人搜索、查询、详情、创建、修改和删除，遵守系统授予的可见范围。

#### Scenario: 修改并查询联系人

- **WHEN** 项目获准访问一名联系人，用户通过项目修改其电话号码
- **THEN** 系统通讯录和项目再次查询都返回更新值，项目只能取得授权范围内的联系人。

### Requirement: Notifications

SDK SHALL 提供本地通知授权、创建、定时与重复调度、撤销、类别、点击事件及状态查询，并按来源项目保存通知响应。

#### Scenario: 项目关闭后用户点击通知

- **WHEN** 系统送达 A 的已调度通知，用户点击并打开宿主
- **THEN** 点击结果归属 A，在 A 会话可用时交付，通知的送达本身不作为项目代码已执行的证据。

### Requirement: Bluetooth

SDK SHALL 提供蓝牙状态、扫描、连接、断开、服务与特征发现、GATT 读写、订阅通知、连接事件和错误。

#### Scenario: 与真实外设交互

- **WHEN** 项目连接提供可读写及通知特征的外设，发现服务并订阅，随后外设断开
- **THEN** 读写及通知与外设实际值一致，项目收到断开事件，未完成操作返回错误并释放连接资源。

### Requirement: NFC

SDK SHALL 提供设备和已签名能力支持的标签读取、NDEF 读取、标签交互、会话状态及错误，并区分硬件不可用、未获签名、取消与超时。

#### Scenario: 读取 NDEF 标签

- **WHEN** 用户在具备条件的 iPhone 上主动开始会话并靠近可读标签
- **THEN** 项目取得真实 NDEF 记录和会话结束原因。用户提前结束时返回取消状态。

### Requirement: HealthKit

SDK SHALL 检查可用数据类型，在系统允许的范围内查询步数、心率、睡眠、活动和运动记录，写入支持的类型，并按类型返回系统公开的授权信息。

#### Scenario: 数据可见范围有限

- **WHEN** 用户按类型授权后，项目查询某个日期范围并尝试写入一个支持的样本
- **THEN** 查询只返回系统可见记录，写入按独立的写入授权返回成功或拒绝，读取空集不会生成模拟样本。

### Requirement: HomeKit

SDK SHALL 提供已授权家庭、配件、特征状态、可写特征修改、场景查询与执行及状态变化订阅。

#### Scenario: 调整家庭配件

- **WHEN** 项目对已有家庭中的可写特征发起修改并订阅状态
- **THEN** 项目收到配件返回的实际结果及后续状态变化，离线配件或只读特征返回明确错误。

### Requirement: Security

SDK SHALL 通过项目隔离的 Keychain、安全随机数、哈希、加解密及 LocalAuthentication 提供凭证和生物识别能力，按设备实际支持的 Face ID 或 Touch ID 工作。

#### Scenario: 生物识别保护的凭证

- **WHEN** 用户在支持的设备验证身份并保存凭证，随后切换到其他项目
- **THEN** 原项目可依照凭证策略取用，其他项目读不到该项，凭证明文不会出现在项目文件或诊断记录。

### Requirement: System

SDK SHALL 提供剪贴板读写、系统分享、URL Scheme 与 Universal Links、触觉反馈、亮度、设备和电池信息、系统版本、深色模式、系统允许的方向控制、文档预览、设置入口及网络状态。

#### Scenario: 从项目打开系统功能

- **WHEN** 用户预览项目文档、打开已配置的链接或请求改变屏幕方向
- **THEN** 系统展示对应文档并报告链接处理或方向请求的实际结果。设备或系统拒绝时，项目能够区分拒绝和成功。

### Requirement: Network

SDK SHALL 按项目与系统策略处理 HTTP/HTTPS 的 GET、POST、PUT、PATCH、DELETE、WebSocket、文件上传下载、进度、取消、超时、网络状态和证书验证。

#### Scenario: 传输中断或服务器证书无效

- **WHEN** 项目执行获准的传输后取消，或连接到证书验证失败的目标
- **THEN** 已传输字节和终态对应同一请求，取消和证书错误可区分，未验证的响应内容不会作为成功返回。

### Requirement: Graphics and Compute

SDK 与 Web 运行环境 SHALL 提供 Canvas、WebGL、WebAssembly、二维和三维绘图、动画、可视化、图像处理、SQLite、大文件分块处理及原生媒体处理，并能查询设备可用性。

#### Scenario: 本地计算并持久化结果

- **WHEN** 项目加载本地 Wasm 计算资源，以 Canvas 或 WebGL 绘制结果，并分块读取大文件后将索引写入项目数据库
- **THEN** 图像与输入一致，数据库结果可在重开后读取，文件处理无需把整个文件复制到网页消息中。
