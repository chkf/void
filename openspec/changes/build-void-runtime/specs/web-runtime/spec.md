# Spec Delta

## Purpose

项目可以使用完整的 HTML 应用，也可以从原生导航打开一个独立的 Web 页面。它们使用同一项目的资源和权限，各项目的来源、执行会话和可见文件彼此隔离。

## ADDED Requirements

### Requirement: 运行本地项目页面

运行时 SHALL 支持 HTML、CSS、JavaScript、ES Modules、Promise 和 async/await，加载图片、字体、音频、视频及项目内路由，支持静态资源缓存、CSS 动画、深色模式与不同 iPhone 屏幕。

#### Scenario: 离线打开嵌套路由

- **WHEN** 用户在离线设备上打开已有有效构建的嵌套路由
- **THEN** 页面取得本版本的入口、脚本、样式和媒体，刷新后仍能定位同一路由，系统外观和窗口尺寸变化对页面可见。

### Requirement: 隔离页面来源和本地资源

运行时 SHALL 为项目界定内容来源与内容安全策略。页面只可读取当前发布版本所暴露的资源，网络访问服从项目策略，外部页面无法继承项目的原生调用权。

#### Scenario: 读取发布目录之外的文件

- **WHEN** 页面、子框架或依赖请求另一个项目的资源、书签、数据库文件或可跳出资源根的链接
- **THEN** 请求被拒绝，响应不泄露目标内容，当前项目仍可加载自身已发布的资源。

#### Scenario: 变更生效后再次访问同名资源

- **WHEN** 发布了内容不同但文件名相同的新资源
- **THEN** 新版本读取对应的新内容，原有页面的资源请求继续指向其所属版本，直至会话结束。

### Requirement: Web 页面生命周期

运行时 SHALL 支持从清单启动完整 Web 应用，也支持从原生项目页面导航到指定 Web 页面。关闭页面后须清理该会话的资源，保留项目已提交的数据。

#### Scenario: 从原生详情页打开交互图表

- **WHEN** 用户从原生详情页打开项目的本地 WebGL 图表，再返回详情页
- **THEN** 图表能使用当前项目获准的资源，原生详情仍在原导航位置，图表页面的订阅已释放。
