# 在 iPhone 上运行

首次启动进入「项目」。点击「创建项目」，输入名称，可选择「在此 iPhone 创建」或系统文件夹。导入时可选择一个项目，也可选择含多个项目的父目录。登记与上次打开的项目保存在宿主私有目录。

在 Files 中打开项目的 `app/src/main.tsx`，修改文字或开关标签后保存。回到宿主时会重新检查源码。构建成功后，原生模板在第一棵有效的 SwiftUI 控件树到达时成为当前版本。Web 页面在入口加载确认后成为当前版本。

屏幕底部的「管理」由宿主绘制，可切换项目、重命名、查看权限声明与本次会话日志、重新构建和重新授权。已运行过两个不同版本时，可恢复前一可运行版本。用户共享数据保存在原目录。
