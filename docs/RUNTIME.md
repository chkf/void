# 在 iPhone 上运行

首次启动进入「项目」。点击「创建项目」，输入名称，可选择「在此 iPhone 创建」或系统文件夹。导入时可选择一个项目，也可选择含多个项目的父目录。登记与上次打开的项目保存在宿主私有目录。

新建后先进入工作区，可查看需要编辑的入口文件，再点「预览项目」。第一次成功预览前，退出或重开都会回到工作区。要整理历史，在「最近项目」向左滑动并点「移除记录」。原目录与项目数据保留，重新导入原目录可继续使用。

创建时默认选择 SwiftUI。页面中的名字输入框绑定到 Swift 的 `@State`，开关可以隐藏或显示问候。要修改页面，编辑 `ios/StarterProject/app/SwiftUI/ProjectContentView.swift` 并通过 GitHub Actions 编译。签名并安装新版 IPA 后，用新版模板创建项目，或将既有项目的 `app/SwiftUI/` 同步到相同版本。如果先在「文件」中编辑了项目源码，宿主会提示将改动同步回仓库。[SwiftUI 入口](../ios/StarterProject/app/SwiftUI/ProjectContentView.swift) · [构建与签名](BUILD.md)

选择 React / TSX 模板时，可在「文件」中编辑 `app/src/main.tsx`。回到宿主后，编译成功的脚本会提交新的 SwiftUI 控件树。Web 项目在 HTML 入口加载确认后成为当前版本。

预览会依次显示读取目录、启动编译器、编译、核对源码和等待项目首屏。离线编译器首次启动超时时，宿主会自动重试一次。可在进度旁取消。若预览过程中退出，重开后先进入项目列表并显示中断阶段。点原项目名称可再次预览。「目录诊断」可查看编译及首屏阶段、内存警告和 WebKit 进程终止事件。

项目概览和工作区右上角可以打开设置，左上角可以返回项目列表。预览中，打开子应用自己的设置，点「项目管理」可以切换或重命名项目、查看权限与运行日志。更新失败时，也可以从错误旁的「预览选项」打开项目管理或收起提示。旧项目尚未接入、又需要切换项目时，可在 iOS 系统「设置」里找到 void，开启「启动时打开项目列表」，再完全退出并重开 void。

「重新扫描并预览」使用原登记的目录。带标签的项目可在管理页的「恢复」中找到重建、还原、重新授权和目录诊断。脚本项目已运行过两个不同版本时，可恢复前一可运行版本。点「扫描本机项目」后，进度和结果显示在项目列表的操作分组中。取消系统文件选择会回到原页。导入单个项目后直接进入该项目，重新授权的结果可在「重新授权文件夹」旁查看。[目录核验与错误说明](FILESYSTEM.md)

## 在子应用自己的设置里接入项目管理

开发子应用时，把「项目管理」放在用户原本就会去的设置页面，沿用该页的列表和分组。例如健身应用可以放在「我的 → 设置 → 项目管理」，首页和五个底部标签都由健身应用自己定义。下面三个例子都打开当前项目的同一个管理面板，无需声明权限。

**React / TSX 原生页面**可以从 `@runtime/ui` 导入管理行。将它放在现有的 `Form` 或 `List` 的分组中，也可以放进设置页已有的 `ScrollView`。该组件从宿主 dev.13 起提供，支持 UI 依赖 `1.0.0` 和 `1.1.0`。页面可以叫「我的」「偏好」或使用自定义路由。

```tsx
import { Section, ProjectManagementButton } from "@runtime/ui";

// 在「我的」页面已有的设置表单中使用 <AppSettings />。
function AppSettings() {
  return <Section title="设置"><ProjectManagementButton /></Section>;
}
```

**SwiftUI 页面**可在应用自己的设置表单里使用同名控件。修改 Swift 源码后需重新编译 IPA。

```swift
Form {
    Section("设置") { ProjectManagementButton() }
}
```

**HTML 或 React DOM 页面**可将普通链接放进已有设置列表，并使用项目自己的样式。链接由当前页面在本窗口打开。

```html
<a href="void://project/management">项目管理</a>
```

升级已有 TSX 应用时，宿主会沿用原有的「设置」分组，或沿用 ID 为 `settings`、标题为「设置」或「Settings」的原生标签。显式放置管理行后，其位置由项目决定。[原生组件和可导入示例](NATIVE_UI.md)
