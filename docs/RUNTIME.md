# 在 iPhone 上运行

首次启动进入「所有项目」，列表按名称排序。把项目放在「文件 → 我的 iPhone → void → 项目名」，文件夹内应有有效的 `app/manifest.json`。每次启动 void 都会先识别这些项目。列表打开时，后来放入的项目也会自动出现。

「创建项目」中的「普通创建」可在此 iPhone 或所选文件夹生成 React 项目。创建成功后，点「打开 OpenMinis」前往编辑，或点「完成」回到项目列表。如果 OpenMinis 需要访问新文件夹，可在 OpenMinis 中选择该目录。

「导入文件夹」可以选择一个外部项目，也可以选择含多个项目的父目录。void 将每个项目的整个文件夹复制到自己的文稿目录，此后编辑和预览都使用这份副本。已经在 void 文稿里的项目可就地打开。遇到同名文件夹或项目 ID 冲突时，导入会提示原因。登记与上次打开的项目保存在宿主私有目录。

点按项目名称，在弹窗中点「启动」即可运行，点「取消」留在列表。长按项目，点「详情」可查看 `app/manifest.json` 中的版本。点详情中的「项目名称」并保存，列表、清单和「文件」中的项目文件夹会同步改名，原有数据与权限继续跟随该项目。向左滑动可从列表移除，重新导入原目录可恢复记录。

要从公开 GitHub 仓库运行项目，在「创建项目 → 从 GitHub 导入」粘贴仓库的 HTTPS 地址，点「克隆并运行」。void 使用仓库默认分支，根目录需包含 `app/manifest.json`，并提供相应的入口和依赖。克隆后的源码位于 void 文稿内。要更新，长按项目并选「拉取并运行」。void 快进到该分支的新提交，保留互不冲突的本地编辑。遇到冲突时可在「文件」处理本地改动后重试。

新建项目都使用 React / TSX。编辑项目目录里的 `app/src/main.tsx`，就能修改示例表单中的问候语、开关和设置页。回到 void 预览时，宿主在手机上编译 TSX 并用 SwiftUI 显示原生控件。[示例入口](../ios/TSXProject/app/src/main.tsx)

已有的 SwiftUI 项目按已安装 IPA 中编译的视图运行。修改这类项目的 Swift 源码后，需将 `app/SwiftUI/` 同步到仓库，通过 GitHub Actions 构建并安装匹配的 IPA。已有 Web 项目按清单中的 HTML 入口加载。[构建与签名](BUILD.md)

预览会依次显示读取目录、启动编译器、编译、核对源码和等待项目首屏。离线编译器首次启动超时时，宿主会自动重试一次。可在进度旁取消。若预览过程中退出，重开后先进入项目列表并显示中断阶段。点原项目名称可再次预览。后台诊断记录编译及首屏阶段、内存警告和 WebKit 进程终止事件。[读取后台诊断](FILESYSTEM.md)

要切换项目，在子应用自己的设置里点「项目管理」，即可回到「所有项目」。启动进度显示在列表上方，可点「取消」退出。预览更新失败时，错误旁的「预览选项」提供「返回项目列表」和「收起提示」。遇到尚未接入设置入口的旧项目，可在 iOS 系统设置里为 void 开启「启动时打开项目列表」，再完全退出并重开 void。

在项目列表右上角点「设置」可查看 void 的应用版本，进入「语言」可在简体中文和 English 之间切换。选择即时生效并在重启后保留。Agent 可在新建 TSX 项目的文件夹中读取 `SDK_REFERENCE.md` 和 `types/runtime-sdk.d.ts`。[原生控件版本](NATIVE_UI.md) · [SDK 接口与权限](SDK_REFERENCE.md)

## 在子应用自己的设置里接入项目管理

开发子应用时，把「项目管理」放在用户原本就会去的设置页面，沿用该页的列表和分组。例如健身应用可以放在「我的 → 设置 → 项目管理」，首页和五个底部标签都由健身应用自己定义。下面三个例子都直接返回宿主的项目列表。

**React / TSX 原生页面**可以从 `@runtime/ui` 导入管理行。将它放在现有的 `Form` 或 `List` 的分组中，也可以放进设置页已有的 `ScrollView`。该组件从宿主 dev.13 起提供，支持 UI 依赖 `1.0.0` 和 `1.1.0`。页面可以叫「我的」「偏好」或使用自定义路由。

```tsx
import { Section, ProjectManagementButton } from "@runtime/ui";

// 在「我的」页面已有的设置表单中使用 <AppSettings />。
function AppSettings() {
  return <Section title="设置"><ProjectManagementButton /></Section>;
}
```

**SwiftUI 页面**可在应用自己的设置表单里使用同名控件。修改 Swift 源码后需重新编译 IPA。

```swift
Form {
    Section("设置") { ProjectManagementButton() }
}
```

**HTML 或 React DOM 页面**可将普通链接放进已有设置列表，并使用项目自己的样式。链接由当前页面在本窗口打开。

```html
<a href="void://project/management">项目管理</a>
```

升级已有 TSX 应用时，宿主会沿用原有的「设置」分组，或沿用 ID 为 `settings`、标题为「设置」或「Settings」的原生标签。显式放置管理行后，其位置由项目决定。[原生组件和可导入示例](NATIVE_UI.md)
